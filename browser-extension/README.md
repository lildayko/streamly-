# Моя главная YouTube в Streamly

1. Открой chrome://extensions (в Edge — edge://extensions).
2. Включи режим разработчика → «Загрузить распакованное расширение» → выбери эту папку с manifest.json.
3. Обнови вкладки Streamly и YouTube. Войди в нужный аккаунт на youtube.com.
4. В Streamly нажми «Импортировать мою ленту». После первого импорта рекомендации видны внутри Streamly и подгружаются при прокрутке.

Поддерживаются локальные адреса http://localhost:3000 и http://127.0.0.1:3000. Оставляй главную YouTube открытой. Для персональных рекомендаций в плеере расширение использует вкладку соответствующего видео: если её нет, откроет её без звука. Учти, что это обычная вкладка YouTube и её воспроизведение может учитываться в истории YouTube.

Расширение читает только карточки главной и боковой панели выбранного видео. Cookies, пароли, внутренние API-ключи, история аккаунта и содержимое сообщений не передаются. Публикации, лайки и подписки не выполняются. Данные карточек поступают только в локальную страницу Streamly. Снимок главной хранится в localStorage этого браузера.

Если список пуст, проверь выбранный аккаунт и наличие рекомендаций на самой главной. Вкладка с проверкой возраста, согласием, ошибкой сети или входом не содержит доступной ленты. При изменении разметки YouTube расширению может потребоваться обновление. Firefox и мобильные браузеры в этой версии не поддерживаются. Это импорт видимых рекомендаций из вкладки, а не официальный API главной YouTube.
